# Smart Task Management System

## Features
- User Authentication
- Task CRUD APIs
- PostgreSQL Database
- Analytics using Pandas
- WebSocket Live Updates
- Basic Frontend UI

## Setup

1. Install dependencies:
pip install -r requirements.txt

2. Setup PostgreSQL:
Create DB: taskdb

3. Run:
python app.py

## APIs
- POST /register
- POST /login
- POST /tasks
- GET /tasks
- PUT /tasks/<id>
- DELETE /tasks/<id>
- GET /analytics
